# 📱 Google Play Store Analytics

## 📌 Project Overview

This project analyzes Google Play Store application data using Python and Jupyter Notebook. It explores app categories, ratings, installs, reviews, pricing, and user engagement through data cleaning, visualization, and exploratory data analysis (EDA).

---

## 🎯 Objectives

- Analyze Google Play Store app data
- Clean and preprocess the dataset
- Handle missing and duplicate values
- Perform Exploratory Data Analysis (EDA)
- Create meaningful visualizations
- Generate business insights

---

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/YOUR_USERNAME/Google-Play-Store-Analytics.git
```

2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

3. Open the notebooks in Jupyter Notebook or VS Code and run all cells.

---

## 📈 Key Insights

- Family and Game are among the largest app categories.
- Most Play Store apps are free.
- Paid apps generally receive slightly higher ratings.
- Revenue varies significantly across categories.
- App updates influence ratings and user engagement.
