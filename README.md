# Data-Analysis-Internship-Project

## Description
This repository contains my internship project completed using Python and Jupyter Notebook.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files
- Analysis.ipynb
- Analysis2.ipynb
- Analysis3.ipynb

## How to Run
1. Install Python 3.x
2. Install Jupyter Notebook
3. Install required libraries:
   pip install pandas numpy matplotlib seaborn
4. Open the notebooks in Jupyter Notebook or VS Code.
